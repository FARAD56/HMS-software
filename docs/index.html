Features

One record of the visit, seen by everyone who needs it

Each person gets their own dashboard. What the nurse records at the front desk is what the doctor sees in the consulting room and what the patient sees at home.

Vitals and triage

Staff record temperature, blood pressure and a triage level (normal, severe or critical) for each patient, so the most urgent cases are visible first.

Diagnoses and prescriptions

Doctors record a diagnosis, then attach prescriptions with medicine, strength, dose, frequency and duration, all from structured choices instead of free text.

Investigations and referrals

Order blood tests, urinalysis, biopsies or thyroid tests against a diagnosis, with the unit and the referral facility recorded alongside.

Telemedicine with Google Meet

Patients book a doctor's open slot, and the system creates a Google Calendar event with a Meet link for both of them.

Charts that update themselves

Chart.js dashboards show diagnoses across the hospital, patient demographics, and each patient's temperature and blood pressure over the last six days.

Personal activity lists

Doctors and patients keep their own to-do lists with deadlines labelled "Today" or "Tomorrow"; expired items clear themselves from the patient view.

How it works

A visit, from the front desk to follow-up

  1. A nurse books the patient in. Vitals and a triage level are saved against the patient's ID.
  2. The doctor consults. A diagnosis is recorded, and prescriptions and investigations hang off it.
  3. The patient follows up from home. Their dashboard shows medication, appointments and vitals trends, and they can book a Google Meet consultation.

Quick start

Running locally in a few commands

You'll need Python 3.10+ and, for telemedicine, a Google Cloud OAuth client with the Calendar API enabled.

1 · Install
git clone https://github.com/FARAD56/HMS-software.git
cd HMS-software/HMS
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
2 · Run
# then open http://localhost:8000
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
